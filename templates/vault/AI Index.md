# AI Index

Entry point for coding agents. Read this first, then `Shared/Agent Memory/INDEX.md`.

## How this vault is used

- Notes are plain markdown in English. Humans read them in Obsidian; agents read and write the same files.
- Durable facts that more than one agent should know go in `Shared/Agent Memory/` (one fact per note, listed in `INDEX.md`).
- Project notes go in their own folder; add a line for each project below.
- Never put secrets in this vault (keys, tokens, passwords, personal data): it may be backed up to a remote.
