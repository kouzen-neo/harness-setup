# Starting a new project

- Always ask the owner about the tech stack before starting a new project, and propose a stack that fits the use case.
- Use modern, current technology: check the latest stable versions of languages, frameworks, and libraries (docs or the web) instead of relying on memory, and never pick a legacy or deprecated stack.
- Choose by use case, not by habit: explain briefly why each choice fits, and note the trade-offs of the main alternatives.
